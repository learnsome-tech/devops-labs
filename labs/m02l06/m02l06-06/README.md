## Goal

You can run administrative tasks as one-off processes against the same release, and you can describe accurately what changed when the manifesto was open sourced in 2024, including the proposals in flight.

In the lesson: Now the update, because the manifesto stopped being frozen. In November twenty twenty four it was open sourced under a Creative Commons licence, with work moving to a public repository and a branch where the revised text is being assembled. The maintainers have stated an intention to keep the number of factors at twelve rather than letting the list grow, which makes the proposals more interesting than they would otherwise be: a new factor has to displace an existing one. Until that revision lands, the text published in twenty eleven is still the reference, and it is what this module has taught.
